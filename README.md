# java-racingcar-precourse

## 기능 명세
### 1. 경주에 참여하는 자동차 변수 선언
사용자 입력 텍스트 데이터를 통해 경주에 참여하는 자동차의 변수명을 선언받음.
양식 요건 충족 여부에 따라 기능의 작동 여부가 결정됨.

### 2. 자동차 이동 횟수 입력
사용자는 몇 번의 이동을 할 것인지 숫자 형태로 입력한다.

입력받은 숫자는 횟수를 지칭하는 변수에 저장하여 관리한다.

### 3. 자동차 이동 기능 구현
사용자가 입력한 횟수를 for 반복문으로 실행하여, 각 자동차별로 0-9 사이 랜덤한 값을 입력받아 조건에 맞게 이동 처리한다.
이 때 반복문은 사용하지 않기 위해 자동차 이동 로직은 class로 별도 분류한다.

#### 3.1 자동차 최초 위치 초기 세팅
자동차의 각 종류와 위치는 딕셔너리 형태로 관리한다. {'a':0,'b':0}

#### 3.2 랜덤 숫자 입력 및 차량 이동 처리
딕셔너리에 요소 갯수를 횟수로 for 반복문을 실행하여, 0~9 사이 랜덤 숫자를 출력하고 "4보다 큰 조건"에 부합하는 지 여부를 판단하여
자동차의 이동 동작을 분기 처리한다. (if num>4 then +1 ~ else pass)
이 때 indentation level: 2 (for, if~else)로 requirement에 부합한 형태를 띤다. 

함수 실행 이후에는 각 자동차의 현 위치를 출력한다.

출력 형태는 "{차량명}: {'_' * 차량 위치 인덱스 번호}"

#### 3.3 자동차 간 위치 비교 및 최종 우승자 선정
정해진 횟수 간 이동이 모두 끝나면 조건에 따라 최고 득점 점수를 산정한다.

### 4. 최종 우승자 정보 출력
최종 우승자는 최고득점에 해당하는 모든 이의 이름을 한 줄로 출력한다.
"최종 우승자 : ," 형식에 맞춰 정보를 출력하고 프로그램을 종료한다.
